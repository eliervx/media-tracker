Pour lancer l'application

Créer un .env à la racine du dossier back comme montré dans .env.example
créer un docker-compose.yml à la racide comme dans docker-compose-example.yml

lancer `docker compose build` pour build le projet (une fois seulement)
lancer `docker compose up -d` pour lancer le projet

Après ouvrez http://localhost:3001
